# Known Issues & Blockers

1. **Sandbox Toolchain Restriction**: In the current execution environment, `node`, `npm`, and `pnpm` are not accessible inside the sandboxed PowerShell session (`NVM_HOME` / `C:\nodejs` are outside sandbox permissions, and `BypassSandbox` is blocked by policy). Consequently, `npm install`, `next build`, `tsc --noEmit`, `vitest`, and `playwright` have **not** been executed in this session. All TypeScript, SQL, and config files should be verified by running `npm install && npm run typecheck && npm run test && npm run build` in a local terminal with Node.js 20+ installed.
2. **External Service Credentials**: Live Supabase project credentials, licensed MapLibre basemap tiles, transactional email provider keys, and Sentry DSN are not configured in `.env.local`. Application code includes clear repository/adapter boundaries and fallback local/in-memory demo-safe handling only where explicitly marked for unconfigured environments, without fabricating live DB/auth passes.
3. **Regulatory & Commercial Gates (External)**: ARCON/DOAS/AMAC legal counsel review, signed operator listing authorizations, and real Abuja field survey data are external operational prerequisites before commercial launch.
